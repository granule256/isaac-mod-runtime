# 新安装模组继续旧局时无存档的修复

也就是说，旧局的isContinued只说明游戏存档存在，不代表新装的CyclingItemsAPI已经写过自己的存档；原作者直接解码空字符串会报JSON错误。

主入口只改一处：非续局或`Isaac.HasModData`为false时沿用作者的空CyclingItems表初始化；确有模组数据时仍加载并正常解码，坏JSON仍会明确报错。没有把LoadModData的合法缺失返回改成假JSON，没有清空已有模组数据。

来源：https://github.com/epfly6/TBoI-Cycling-items-API ，原件保留在dist/test-ready-mods-20261014/mods/CyclingItemsAPI/main.lua。实际Lua回归见runtime/tests/test_cycling_items_resume.py，覆盖首次安装续旧局、已有数据续局、新局三个场景。运行中新增一次仅在开局发生的存档存在性查询；复用持久层缓存，不增加逐帧工作或写入。
