# PC 契约页的**逐字节副本**（进门禁，勿手改）

这 13 个 `.md` 是 PC《以撒的结合：忏悔》模组文档里被我们**引用为契约**的那几页的**逐字节副本**，
供"每条偏离都要写出 `PC 契约：<页>:<行号> 「<原文片段>」`"这条门禁（批次 111）回头核对。

## 为什么要把它们复制进仓库

原来那份完整快照在 `analysis/isaacdocs-snapshot/` 下，而 `analysis/` 是 **gitignore 的**
（它是本机的分析产物，不进门禁）。后果有两层，第二层才是真问题：

1. 干净检出（门禁里那个"只用 `git ls-files` 复制被跟踪文件"的嵌套用例
   `test_game_file_reader_stage10`）里没有这些页 ⇒ **所有契约引用当场失效**（批次 111 第一版
   就是这么被嵌套门禁抓出来的）；
2. 更要紧的是：**契约源不在仓库里 = 这一类工作对任何其他人都不可做**。
   批次 048 撞 `RoomShape` 时的教训一模一样（见 `tools/pc_enum_docs/README.md`）。

## 规矩

* **字节不许变**：`.gitattributes` 标了 `* -text`（行尾不做规范化），
  `runtime/tests/contract/test_api_deviation.py::PcContractCitationTests` 里钉了每一页的**字节数**
  —— 改了要先核对上游，再回来改那个表。
* **只放被引用的那几页**（不是整个快照）：引用到别的页时，把那页也照这样复制进来。
* 引用格式：`PC 契约：tools/pc_contract_docs/<页>.md:<行号> 「<原文里真实出现的片段>」`
  —— 门禁会逐条核对"页在、行在、片段真的在那一行里"。文档里确实没有这一条时，
  写 `PC 契约：文档里没有 <说明>`（也要写明是什么）。
